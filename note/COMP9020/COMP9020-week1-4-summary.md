# COMP9020 - Week 1-4 Summary

> 本笔记按概念组织，而不是按幻灯片顺序组织。符号 `|X|` 表示集合 `X` 的元素个数（cardinality）。

## Numbers, Divisibility and Intervals

### Number Sets

- `N = {0,1,2,...}`：自然数（natural numbers）。
- `P = {1,2,3,...}`：正整数（positive integers），也写作 `N_{>0}` 或 `Z_{>0}`。
- `Z = {...,-2,-1,0,1,2,...}`：整数（integers）。
- `Q = {m/n : m,n ∈ Z, n ≠ 0}`：有理数（rational numbers）。例如 `-3/4`、`5=5/1`。
- `R`：实数（real numbers），可用十进制或二进制小数展开表示；包括有理数和无理数，如 `√2`、`π`。

包含关系：`P ⊂ N ⊂ Z ⊂ Q ⊂ R`。在 `P,N,Z` 中，不同写法代表不同数字；但在 `Q,R` 中，`1/2=2/4=0.5`。

### Floor and Ceiling

`⌊x⌋`（floor）是小于或等于 `x` 的最大整数；`⌈x⌉`（ceiling）是大于或等于 `x` 的最小整数。

例：`⌊3.7⌋=3`，`⌈3.7⌉=4`，`⌊-1.2⌋=-2`，`⌈-1.2⌉=-1`。

常用性质：

```text
⌊-x⌋ = -⌈x⌉,       ⌈x⌉ = -⌊-x⌋
⌊x+t⌋ = ⌊x⌋+t,     ⌈x+t⌉ = ⌈x⌉+t     (t ∈ Z)
```

直观解释：加上一个整数，只是把数轴整体平移该整数距离，所以 floor / ceiling 也相同地平移。

### Counting Multiples in an Interval

若 `k>0`，`m,n ∈ Z` 且 `m≥n`，则闭区间 `[n,m]` 内能被 `k` 整除的整数个数为：

```text
⌊m/k⌋ - ⌊(n-1)/k⌋
```

例：`[5,20]` 内的 `3` 的倍数为 `6,9,12,15,18`，所以有 `5` 个：

```text
⌊20/3⌋ - ⌊4/3⌋ = 6 - 1 = 5
```

证明思路：`⌊m/k⌋` 数出从 `1` 到 `m` 的倍数数目；`⌊(n-1)/k⌋` 数出从 `1` 到 `n-1` 的倍数数目。相减后，剩下的恰好是 `[n,m]` 内的倍数。

### Divisibility and Remainder

`m | n` 读作 “`m` divides `n`”（`m` 整除 `n`），定义为：存在某个 `k∈Z`，使得 `n=k·m`。也可说 `n` is divisible by `m`，或 `n` is a multiple of `m`。

例：`4 | 20`，因为 `20=5·4`；`3 ∤ 10`，因为不存在整数 `k` 使 `10=3k`。

要点：对任意整数 `m`，有 `1|m`、`-1|m`、`m|m`、`m|-m`；对任意 `n`，有 `n|0`。但 `0∤n`，除非 `n=0`，因为除数不能是 0。

`r = n mod m` 表示 `n` 除以正数 `m` 的余数：

```text
n = k·m + r,    0 ≤ r < m
```

例：`17 mod 5=2`，因为 `17=3·5+2`。并且：`m|n` 当且仅当 `n mod m=0`。

### gcd, lcm, Prime and Coprime

- `gcd(m,n)`：`m,n` 的最大公约数（greatest common divisor）。
- `lcm(m,n)`：`m,n` 的最小公倍数（least common multiple）。
- 大于 1 且只可被 `1` 和自身整除的正整数叫 prime（质数）。
- 若 `gcd(m,n)=1`，则 `m,n` relatively prime / coprime（互质）。

例：`gcd(12,18)=6`，因为共同因数为 `1,2,3,6`；`lcm(12,18)=36`，因为 `36` 是最小的共同倍数。符号正负不影响它们：`gcd(-4,6)=2`，`lcm(-5,-5)=5`。`gcd(0,n)=|n|`（`n≠0`）；`gcd(0,0)` 未定义，因为每个正整数都同时整除 0，没有“最大”的那个。

重要公式（当 `m,n≠0`）：

```text
gcd(m,n) · lcm(m,n) = |m|·|n|
```

理解证明：把 `m,n` 分解为质因数。例如 `12=2²·3`，`18=2·3²`。gcd 对每个质数取较小指数（`2·3=6`），lcm 取较大指数（`2²·3²=36`）；相乘后，每个质数的指数相加，刚好得到 `|m|·|n|`。

推论：对正整数 `m,n`，若 `lcm(m,n)=m·n`，则 `gcd(m,n)=1`，所以它们互质。反之亦成立。

### Euclid's gcd Algorithm

较慢版本不断以较大的数减去较小的数，直到两数相等；最后的数就是 gcd。关键事实是（`m>n`）：

```text
gcd(m,n)=gcd(m-n,n)
```

证明：对任何整数 `d`，

```text
d|m 且 d|n    当且仅当    d|(m-n) 且 d|n。
```

正向：若 `m=a·d,n=b·d`，则 `m-n=(a-b)·d`。反向：若 `m-n=c·d,n=b·d`，则 `m=(m-n)+n=(c+b)·d`。两边拥有完全相同的共同因数，因此 gcd 相同。

更快的递归版本是：

```text
gcd(m,n):
  if n=0 return m
  else return gcd(n, m mod n)
```

理由是 `m=q·n+r`，所以共同因数同时整除 `m,n`，当且仅当同时整除 `n,r=m mod n`。余数 `r<n`，故数字会严格变小，算法终止。

### Intervals

```text
[a,b] = {x : a≤x≤b}       (a,b) = {x : a<x<b}
[a,b) = {x : a≤x<b}       (a,b] = {x : a<x≤b}
```

例：在整数集合 `Z` 中，`[-1,1]={-1,0,1}`，有 3 个元素；但在 `R` 中，`[-1,1]` 有无限多个实数。若 `m≤n` 且只讨论整数，`[m,n]={m,m+1,...,n}`，所以 `|[m,n]|=n-m+1`。

## Sets

### Sets, Elements and Cardinality

set（集合）是元素的无序集合，重复不计数。

```text
{a,b,c} = {a,a,b,b,b,c} = {b,c,a}
```

`x∈S` 表示 `x` 是 `S` 的元素。`∅` 或 `{}` 是空集。`|X|` 是集合 `X` 的元素个数。

例：`|{a,{a}}|=2`，因为它有两个不同元素：`a` 和集合 `{a}`。务必区分 `a∈{a,b}` 与 `{a}⊆{a,b}`：前者说 `a` 是元素，后者说 `{a}` 是子集。

### Set-builder Notation

集合可列举，也可用性质定义：

```text
S = {x∈X : P(x)}
```

意思是：从 universe / 全集 `X` 中取所有满足性质 `P(x)` 的元素。

例：`{n∈N : 2|n}={0,2,4,6,...}`，即所有偶自然数。

### Union, Intersection and Disjointness

```text
A∪B：属于 A 或 B 的元素
A∩B：同时属于 A 和 B 的元素
```

例：若 `A={1,2,3}`、`B={3,4}`，则 `A∪B={1,2,3,4}`，`A∩B={3}`。若 `A∩B=∅`，则 A 和 B 是 disjoint（不相交）。

### Difference, Symmetric Difference and Complement

```text
A\B：属于 A 但不属于 B
A⊕B = (A\B)∪(B\A)：只属于其中一个集合
Aᶜ：相对于给定 universe 的补集，即不属于 A 的元素
```

例：`A={1,2,3}`，`B={3,4}`，则 `A\B={1,2}`，`A⊕B={1,2,4}`。若全集 `U={1,2,3,4,5}`，则 `Aᶜ={4,5}`。没有指定 universe 时，补集 `Aᶜ` 不能确定。

### Laws of Set Operations

常考恒等式：

```text
A∪B=B∪A,            A∩B=B∩A                 (commutativity)
(A∪B)∪C=A∪(B∪C),   (A∩B)∩C=A∩(B∩C)        (associativity)
A∪(B∩C)=(A∪B)∩(A∪C)                         (distribution)
A∩(B∪C)=(A∩B)∪(A∩C)
A∪A=A, A∩A=A                                  (idempotence)
A∪∅=A, A∩∅=∅                                  (identity)
(Aᶜ)ᶜ=A                                        (double complement)
(A∪B)ᶜ=Aᶜ∩Bᶜ,  (A∩B)ᶜ=Aᶜ∪Bᶜ                 (De Morgan)
```

证明技巧：要证集合相等 `X=Y`，通常证两个方向：`X⊆Y` 和 `Y⊆X`。例如证明 `(A\B)∪(B\A)=(A∪B)\(A∩B)`：左边元素要么“在 A 不在 B”，要么“在 B 不在 A”；两种情况都属于 `A∪B` 且不属于 `A∩B`。反向亦然：右边元素在 A 或 B 中、但不能同时在两者中，因此恰好落入左边其中一项。

### Subsets and Power Sets

`S⊆T` 表示 S 的每个元素都属于 T；允许 `S=T`。`S⊂T` 表示 proper subset（真子集）：`S⊆T` 且 `S≠T`。

例：`{a}⊆{a,b}`，但 `a∉{{a},{b}}`；`a` 与 `{a}` 类型不同。每个集合都有 `∅⊆X`。

power set（幂集）定义为：

```text
Pow(X) = {A : A⊆X}
```

即 `X` 的所有子集组成的集合。例：若 `X={a,b}`，

```text
Pow(X)={∅,{a},{b},{a,b}},    |Pow(X)|=4=2²。
```

一般若 `X` 有 `n` 个元素，则 `|Pow(X)|=2^n`。证明：每个元素独立地有两种选择——放进子集或不放进子集——由乘法原理共 `2·2·...·2=2^n` 种。

### Cardinality Formulas

对有限集合：

```text
|A∪B|=|A|+|B|-|A∩B|
|A\B|=|A|-|A∩B|
|A⊕B|=|A|+|B|-2|A∩B|
```

第一式的理由：直接加 `|A|+|B|` 时，交集元素被数了两次，所以减去一次。例：`|A|=5, |B|=4, |A∩B|=2`，则 `|A∪B|=5+4-2=7`。

## Cartesian Products and Functions

### Cartesian Product

```text
S×T = {(s,t) : s∈S, t∈T}
```

即从 `S` 选第一个元素、从 `T` 选第二个元素而组成的所有 ordered pairs（有序对）。例：`{1,2}×{a,b}={(1,a),(1,b),(2,a),(2,b)}`；一般 `(s,t)` 与 `(t,s)` 不同。

多集合版本：

```text
×ᵢ₌₁ⁿ Sᵢ = {(s₁,...,sₙ) : sₖ∈Sₖ for every 1≤k≤n}
```

意思是第 `k` 个位置从 `Sₖ` 选。`S²=S×S`，`S³=S×S×S`。

事实：`∅×S=∅`，因为第一个位置没有可选元素。若集合有限，`|S×T|=|S|·|T|`，以及 `|×ᵢ₌₁ⁿSᵢ|=∏ᵢ₌₁ⁿ|Sᵢ|`。证明：每一个 `s∈S` 都有 `|T|` 种第二项可配对，共有 `|S|` 组；这就是乘法原理。

### Functions

```text
f:S→T
```

表示函数 `f` 从 domain（定义域）`S` 到 codomain（陪域）`T`：每个 `s∈S` 都被分配到唯一的 `t∈T`。写 `f:s↦t` 等同于 `f(s)=t`。

例：`f:{1,2,3}→{a,b,c}`，定义 `f(1)=a,f(2)=a,f(3)=c`，仍是函数；不同输入可有相同输出。若 `f(1)=a` 又 `f(1)=b`（`a≠b`），则不是函数。

## Formal Languages

### Alphabet and Words

`Σ`（sigma）是 alphabet（字母表/符号集）：有限且非空。它不限于英文字母。例：`Σ={0,1}` 可用于二进制数；所有中文字符也能组成一个形式字母表。

word（字）是由 `Σ` 中符号组成的任意有限字符串。`λ` 是 empty word（空字符串）。例：在 `Σ={a,b}` 下，`aba` 是 word，`length(aba)=3`，而 `length(λ)=0`。

concatenation（连接）就是直接拼接：若 `ν=ab,ω=ba`，则 `νω=abba`。有：

```text
λω=ω=ωλ,        length(νω)=length(ν)+length(ω)
```

### Σᵏ, Σ*, Σ+ and Languages

`Σᵏ` 是所有长度恰好为 `k` 的 words 的集合。`Σ⁰={λ}`，`Σ¹=Σ`。

例：若 `Σ={a,b}`，则 `Σ²={aa,ab,ba,bb}`。

```text
Σ* = Σ⁰∪Σ¹∪Σ²∪...       （全部有限字符串，含 λ）
Σ+ = Σ¹∪Σ²∪... = Σ*\{λ} （全部非空字符串）
Σ≤n = Σ⁰∪Σ¹∪...∪Σⁿ
```

language（语言）是 `Σ*` 的子集：`L⊆Σ*`。例：`Σ={0,1}`，`L={所有以 1 结尾的二进制字符串}`。grammar（文法）是一组规则，用来描述或生成哪些 strings 属于某个 language；程序设计语言和数据库查询语言都有文法。

计数例：若 `|Σ|=3`，则 `|Σ≤4|=3⁰+3¹+3²+3³+3⁴=121`；因为每个长度为 `k` 的 word 有 `3^k` 种可能。

## Propositional Logic and Proofs

### Propositions and Proofs

proposition（命题）是能够有意义地判断真或假的陈述句。例如“`√16` 的一个平方根是 4”是命题；命令、问题和无意义句子不是命题。

数学证明是：从公理、定义、已知定理等基础出发，经由一连串 logical deductions（逻辑推导），最后得到要证明的命题 `p`。证明不是“很多例子都对”，而是说明所有允许情况都必然成立。

### Connectives and Truth Tables

设 `p,q` 为命题：

```text
¬p：not p（非）
p∧q：p and q（且）
p∨q：p or q（或，包含至少一个为真）
p⇒q：if p then q（蕴含）
p⇔q：p if and only if q（当且仅当）
⊤：永真，⊥：永假
```

`p∧q` 只有两者均真才真；`p∨q` 至少一个真即真；`¬p` 翻转 p 的真假。例：令 `p=(x>0)`，`q=(y>100)`，代码条件 `x>0 or (x≤0 and y>100)` 等价于 `p∨(¬p∧q)`，可用布尔代数化简成 `p∨q`。

### Implication, Necessary and Sufficient Conditions

`A⇒B` 的意思是 “若 A 为真，则 B 为真”。只有 `A` 真而 `B` 假时，它为假。

- `A` is sufficient for `B`：`A⇒B`（A 是 B 的充分条件）。
- `B` is necessary for `A`：`A⇒B`（B 是 A 的必要条件）。
- converse（逆命题）是 `B⇒A`，不能自动认为成立。

例：“程序终止的必要条件是输入正数”。令 `T=程序终止`，`P=输入正数`，正确形式是 `T⇒P`。等价且常用于证明的 contrapositive（逆否命题）是 `¬P⇒¬T`。`P⇒T` 则是“正数输入足以保证终止”，是另一项、更强的主张。

### Unless and Just in Case

课件采用近似翻译：

```text
A unless B    ≈    ¬B⇒A
A just in case B    ≈    A⇔B
```

例：“I go swimming unless it rains” 可写为 `¬rain⇒swim`；它不意味着下雨时一定不游泳。 “The program terminates just in case the input is positive” 写作 `terminates⇔positive input`。

### Formal Language of Propositional Logic

令 `Prop={p,q,r,...}`，并取字母表：

```text
Σ = Prop ∪ {⊤,⊥,¬,∧,∨,⇒,⇔,(,)}
```

formula（公式）是最小的满足下列规则的集合：`⊤`、`⊥` 和每个命题字母是公式；若 `φ` 是公式，则 `¬φ` 是公式；若 `φ,ψ` 是公式，则 `(φ∧ψ)`、`(φ∨ψ)`、`(φ⇒ψ)`、`(φ⇔ψ)` 也是公式。

例：`(p∧¬q)` 是公式；`∧p)` 不是公式。通常优先级为：`¬` 高于 `∧,∨`，它们又高于 `⇒,⇔`，所以 `¬p∧q` 表示 `(¬p)∧q`。

### Satisfiability, Validity and Models

公式 `φ` 是 satisfiable（可满足的），若存在至少一种对其基本命题的真假赋值，使 `φ` 的值为 `T`。令 `p=T,q=T` 时，`p∧q=T`，所以 `p∧q` 可满足。`p∧¬p` 永远为假，因此 unsatisfiable（不可满足）。

公式 `φ` 是 valid / tautology（有效式 / 永真式），记作 `|=φ`，若每一种赋值都使其为真。例：`p∨¬p` 是 tautology；`p∧q` 可满足但不是 tautology。简记：**satisfiable = 至少一行真；tautology = 每一行真。**

在约束问题中，把所有限制以 `∧` 连起来；任何使总公式为真的赋值叫 satisfying assignment（满足赋值）或 model（模型）。例如派对规则 `φ=(J⇒¬S)∧(S⇒K)∧(K⇒J)`：`J=T,S=F,K=T` 是一个 model，即邀请 John 和 Kim、不邀请 Sarah。

### Logical Equivalence

`φ≡ψ` 表示两公式对每一种真假赋值都有相同结果，称为 logically equivalent（逻辑等价）。例如：

```text
p⇒q ≡ ¬p∨q
p⇔q ≡ (p⇒q)∧(q⇒p)
p∨¬p ≡ ⊤,          p∧¬p ≡ ⊥
¬¬p ≡ p
¬(p∧q) ≡ ¬p∨¬q,    ¬(p∨q) ≡ ¬p∧¬q
```

还可使用交换律、结合律和分配律，例如 `p∧(q∨r)≡(p∧q)∨(p∧r)`。证明等价可列完整 truth table，或逐步使用等价定律。若要否定某个“等价”主张，只需找一组使左右真假不同的 counterexample（反例）。

例：

```text
(r∧¬p)∨(r∧q)∨(¬r∧¬p)∨(¬r∧q)
≡ r∧(¬p∨q) ∨ ¬r∧(¬p∨q)
≡ (r∨¬r)∧(¬p∨q)
≡ ¬p∨q
≡ p⇒q.
```

### Arguments and Entailment

argument（论证）由 premises（前提）和 conclusion（结论）组成。记号：

```text
φ₁,...,φₙ |= ψ
```

表示前提 entail（蕴含 / 逻辑推出）结论 `ψ`：真值表中，只要 `φ₁,...,φₙ` 全真，`ψ` 也必真。此时论证 valid（有效）。不关心前提本身为假的行。

例：`Frd∨Tyta, Frd⇒Late, ¬Late |= Tyta`。若 Frank 开 Ford，他会迟到；现在他没迟到；而他必定开 Ford 或 Toyota，因此他只能开 Toyota。

三个重要等价关系：

```text
φ₁,...,φₙ |= ψ    当且仅当    |= (φ₁∧...∧φₙ)⇒ψ
φ≡ψ               当且仅当    |= φ⇔ψ
```

应用于软件 requirements（需求）：若所有需求的合取不可满足，则需求无法同时实现；若 `φ₁,...,φₙ|=ψ`，则每个正确实现都保证 `ψ`；若 `φ₁,...,φₙ₋₁|=φₙ`，则 `φₙ` 是冗余需求。

### Quantifiers

`∀` 表示 for all（对所有），`∃` 表示 there exists（存在）。例：`∀x∈Z,∃y∈Z(y≤x)` 为真，可每次取 `y=x`；但 `∃y∈Z,∀x∈Z(y≤x)` 为假，因为整数没有最小元素。

务必区分：

```text
∃y∀x P(x,y) ⇒ ∀x∃y P(x,y)
```

左边有一个固定的 `y` 能处理全部 `x`，所以右边当然成立；反方向一般不成立，因为右边允许每个 `x` 选择不同的 `y`。

### Proof Methods

**Proof by cases（分类讨论）**：为证明 `A`，找穷尽的情况 `B₁,...,Bₙ`，证明 `B₁∨...∨Bₙ`，并分别证明每个 `Bᵢ⇒A`。

**Proof by contrapositive（逆否证明）**：要证明 `A⇒B`，改为证明 `¬B⇒¬A`，因为两者逻辑等价。

**Proof by contradiction（反证法）**：要证明 `A`，先假设 `¬A`，并推出某个命题 `B` 及其否定 `¬B`；矛盾说明 `¬A` 不可能，因此 `A` 成立。只是在“假设结论不成立”后直接推出结论，并不算真正的反证法——必须明确得到矛盾。

例：证明“若 `n` 是偶数，则 `n²` 是偶数”最自然是直接证明：`n=2k`，故 `n²=4k²=2(2k²)`，所以 `n²` 是偶数。

### Substitution and Equivalent Replacement

substitution（替换）是把一个符号的每次出现都换成一个表达式。例如在 `x²+7y=2xz` 中，用 `2k+3` 替换 `x`，得到 `(2k+3)²+7y=2(2k+3)z`。

逻辑中的重要规则：若 `|=φ(P)`，则对任意公式 `α`，仍有 `|=φ(α)`。例如 `|=P⇒(P∨Q)`，所以 `|=(A∨B)⇒(A∨B∨Q)`。

如果子公式 `α≡β`，那么在任何大公式 `φ` 中以 `β` 替换 `α` 后，整体仍等价：`φ(α)≡φ(β)`。这解释了公式化简时每一步“局部替换”的合法性。

## Boolean Algebra

### Boolean Functions and Notation

一个有 `n` 个输入命题的公式可视为 Boolean function（布尔函数）：`{0,1}ⁿ→{0,1}`，其中 `0=F`、`1=T`。一元、二元和 n 元函数分别称 unary、binary、n-ary。

布尔代数记号和命题逻辑对应如下：

```text
p∧q  ↔  p·q 或 pq
p∨q  ↔  p+q
¬p   ↔  p'
⊥    ↔  0
⊤    ↔  1
```

`+` 和 `·` 不是普通加乘法；例如 `1+1=1`。数字电路可看作计算某个 Boolean function 的装置。

### Boolean Algebra Laws and Simplification

常用化简规则：

```text
x+x=x,       xx=x                         idempotence
xx'=0,       x+x'=1                       complements
x·0=0,       x·1=x,  x+0=x,  x+1=1        identities
(x+y)'=x'y', (xy)'=x'+y'                  De Morgan
(x')'=x                                    double negation
x(y+z)=xy+xz,  x+yz=(x+y)(x+z)            distribution
x+xy=x,     x(x+y)=x                      absorption
xy+xy'=x                                  combining opposites
```

例：`xy+xy'=x(y+y')=x·1=x`。每次化简最好标记所用 law。

### Boolean Algebra as a General Structure

只要一个集合有 `0,1`、join（`+`）、meet（`·`）、complement（`'`），并满足交换、结合、分配、单位元与互补律，它就是 Boolean algebra。

集合幂集是重要例子：对 `Pow(S)`，令 `0=∅`、`1=S`、`X+Y=X∪Y`、`X·Y=X∩Y`、`X'=S\X`。因此集合运算和逻辑运算遵循同一组规律。位向量也一样，例如 `(1,0,1)+(1,1,0)=(1,1,1)`，按位执行 OR。

### CNF and DNF

literal（文字）是 `p` 或 `p'`。CNF（conjunctive normal form，合取范式）的最外层是 AND / `·`，每个 clause 是 literals 的 OR / `+`，如 `(p+q+r')(p'+q)`。DNF（disjunctive normal form，析取范式）的最外层是 OR / `+`，每个 clause 是 literals 的 AND / `·`，如 `p+rsq'`。

每个 Boolean expression 都可转换为等价 CNF 和 DNF。转 CNF 的流程：先用 `p⇒q≡p'+q` 消去蕴含；以 De Morgan 和双重否定把否定推进到 literals；再用分配律获得最外层为 `·` 的形式。DNF 的处理方向相似。

### Canonical DNF

canonical DNF（标准析取范式）从真值表的每一行输出 `1` 构造：变量值为 `1` 就写该变量，值为 `0` 就写其否定；把该行变量全用 `·` 相连，再把所有“真行”的项以 `+` 相连。

例：若 `E` 在 `(x,y)=(0,0),(1,0),(1,1)` 时为 1，则：

```text
E_dnf=x'y'+xy'+xy.
```

它可进一步化简为 `x+y'`。标准形式保证统一表示，但不一定最短。

### Karnaugh Maps

Karnaugh map（卡诺图）是 2、3、4 个变量时的图形化简方法：将真值表的 `1` 标记在格子上，用尽量少且尽量大的矩形覆盖所有 1。矩形大小只能为 `1,2,4,8,...`，不能覆盖 0，边缘可相接（地图像环面）。

合并相邻格的原理是一个变量在其中取真和假，从而消失：`xy+xy'=x(y+y')=x`。因此矩形越大，最终项通常越短。

### Isomorphism

若两个布尔代数间有一一对应，并保持 `0,1,+,·,'`，则它们 isomorphic（同构），记作 `B₁≅B₂`。直觉上是元素名字不同，但运算结构相同。

例：`Pow({a,b,c})≅B³`；子集 `{a,c}` 可编码为位向量 `(1,0,1)`。并集、交集、补集分别对应按位 OR、AND、NOT。

## Week 2 Detailed Preview Notes: Logic, Proofs and Boolean Algebra

### Satisfiable Formula

**Definition：** 若公式 `φ` 在至少一种 truth assignment（给基本命题赋 T/F 的方式）下值为 `T`，则 `φ` 是 satisfiable（可满足的）。

**Explanation：** 只需存在一个可行情况，不要求每一种情况都真。这可用于检查一组时间表、派对规则或系统需求是否能同时实现。

**Example：** `p∧q` 在 `p=T,q=T` 时为真，因此可满足；`p∧¬p` 在任何赋值下都为假，因此不可满足。

### Satisfying Assignment and Model

**Definition：** 使一个可满足公式为真的 assignment 叫 satisfying assignment，也叫 model（模型）。

**Explanation：** formula 是规则本身；model 是一份实际满足规则的选择方案。

**Example：** 对 `φ=(J⇒¬S)∧(S⇒K)∧(K⇒J)`，赋值 `J=T,S=F,K=T` 是一个 model：John 和 Kim 来、Sarah 不来。三个条件分别变成 `T⇒T`、`F⇒T`、`T⇒T`，均为真。

### Valid Formula / Tautology

**Definition：** 若公式 `φ` 对所有 truth assignments 都为真，则它 valid（有效）或是 tautology（永真式），记作 `|=φ`。

**Explanation：** satisfiable 只要求“至少一行真”；tautology 要求“所有行真”。

**Example：** `p∨¬p` 无论 `p` 是 T 还是 F 都为 T，因此是 tautology；`p∧q` 虽然可满足，但当 `p=F` 时为 F，所以不是 tautology。

### Logical Equivalence

**Definition：** 若公式 `φ,ψ` 在每一种基本命题赋值下都有相同真值，则 `φ≡ψ`，称为 logically equivalent（逻辑等价）。

**Explanation：** 等价不表示两个式子外观相同，而表示它们表达完全相同的真假条件。可用真值表证明，也可逐步使用已知等价律。

**Example：** `p⇒q≡¬p∨q`。当 `p=T,q=F` 时，两边都为 F；其他三种赋值时两边都为 T。

### Fundamental Equivalence Laws

**Definition：** 常用等价律包括：

```text
p∨¬p≡⊤                 p∧¬p≡⊥
¬¬p≡p                  p∨⊥≡p, p∧⊤≡p
p∨q≡q∨p               p∧q≡q∧p
¬(p∧q)≡¬p∨¬q          ¬(p∨q)≡¬p∧¬q
p∧(q∨r)≡(p∧q)∨(p∧r)
p∨(q∧r)≡(p∨q)∧(p∨r)
```

**Explanation：** De Morgan's laws 用来把否定推进或拉出括号；distribution（分配律）常用来展开或因式分解逻辑公式。

**Example：** `¬(p∨q)≡¬p∧¬q`。若“p 或 q”不成立，表示 p 不成立且 q 也不成立。

### Counterexample

**Definition：** counterexample（反例）是让某个普遍主张失败的一组具体取值。

**Explanation：** 若要反驳“`φ≡ψ`”，只要找到一组赋值让一边为 T、另一边为 F；不需要检查所有情况。

**Example：** `(p⇒q)⇒r` 不等价于 `p⇒(q⇒r)`。取 `p=F,q=T,r=F`：左边为 `T⇒F=F`，右边为 `F⇒(T⇒F)=T`。

### Argument and Logical Entailment

**Definition：** argument（论证）由 premises（前提）和 conclusion（结论）组成。`φ₁,...,φₙ|=ψ` 表示前提 logically entail（逻辑推出）结论。

**Explanation：** 真值表中，只考察所有前提同时为 T 的行；若每一条这样的行中 `ψ` 也是 T，该论证 valid（有效）。前提为 F 的行不影响有效性。

**Example：** `p⇒q, p |= q`。唯一满足两个前提同时为真的情况是 `p=T,q=T`，此时结论 q 也真；这是 modus ponens 的形式。

### Requirements and Redundancy

**Definition：** 若一组软件需求对应公式 `φ₁,...,φₙ`，且 `φ₁,...,φₙ₋₁|=φₙ`，则最后一条需求 `φₙ` 是 redundant（冗余的）。

**Explanation：** 其他需求已经自动强制 `φₙ` 成立；不写它，系统可实现的行为也不会增加。不过为方便人阅读，实际需求文档有时仍会保留它。

**Example：** `A⇒B, B⇒C |= A⇒C`。因此若前两条已经是需求，`A⇒C` 没有提供新限制。

### Quantifiers

**Definition：** `∀` 是 for all（对所有），`∃` 是 there exists（存在）。

**Explanation：** 量词的顺序极重要：`∀x∃y` 允许每个 x 使用不同 y；`∃y∀x` 要求同一个 y 对全部 x 有效。

**Example：** 在整数中，`∀x∈Z,∃y∈Z(y≤x)` 为真，取 `y=x` 即可；但 `∃y∈Z,∀x∈Z(y≤x)` 为假，因为不存在最小整数。

### Proof by Cases

**Definition：** 为证明命题 `A`，找互相覆盖全部可能性的 cases `B₁,...,Bₙ`，证明 `B₁∨...∨Bₙ`，再分别证明每个 `Bᵢ⇒A`。

**Explanation：** 分类必须不遗漏；两个常见 case 是 `B` 和 `¬B`。

**Example：** 证明任意整数 n 的平方是偶数或奇数。n 要么偶数，要么奇数；若 `n=2k`，则 `n²=2(2k²)` 是偶数；若 `n=2k+1`，则 `n²=2(2k²+2k)+1` 是奇数。

### Proof by Contrapositive

**Definition：** 为证明 `A⇒B`，可证明逻辑等价的逆否命题 `¬B⇒¬A`。

**Explanation：** 当从 A 很难直接得到 B，但从“非 B”很容易推出“非 A”时特别有用。

**Example：** 要证“若 `n²` 是奇数，则 n 是奇数”，证明逆否：“若 n 是偶数，则 `n²` 是偶数”。令 `n=2k`，则 `n²=4k²=2(2k²)` 为偶数，故原命题成立。

### Proof by Contradiction

**Definition：** 为证明 A，先假设 `¬A`，并由此推出某个命题 B 与其否定 `¬B`。矛盾说明 `¬A` 不可能，因此 A 为真。

**Explanation：** 反证的关键不是仅仅“证明了 A”，而是真正出现不可能同时成立的两件事。

**Example：** 证明 `√2` 无理。假设 `√2=m/n` 为最简分数，则 `m²=2n²`，所以 m 偶数，令 `m=2k`；代回得到 `n²=2k²`，所以 n 也偶数。这与 `m,n` 无公因数矛盾，故 `√2` 无理。

### Substitution and Equivalent Replacement

**Definition：** substitution（替换）是把某符号的所有出现替换为表达式；equivalent replacement（等价替换）是在较大公式中以逻辑等价的公式替换一个子公式。

**Explanation：** 若 `|=φ(P)`，把 P 替换为任意公式 α 后仍有 `|=φ(α)`；若 `α≡β`，则 `φ(α)≡φ(β)`。这让逐步公式化简有严格依据。

**Example：** `P⇒(P∨Q)` 永真。用 `A∨B` 替代 P，可得 `(A∨B)⇒(A∨B∨Q)` 仍永真。

### Boolean Function

**Definition：** 有 n 个命题变量的公式可看作函数 `{0,1}ⁿ→{0,1}`，称为 Boolean function（布尔函数）；`0=F`、`1=T`。

**Explanation：** 一个公式的真值表就是这个函数的输出表；数字电路正是在计算这类函数。

**Example：** `f(A,B)=(¬A∨¬B)∧B` 的输出在 `(A,B)=(0,1)` 时为 1，其他三种输入时为 0。

### Boolean Algebra Notation and Laws

**Definition：** 布尔代数通常写 `p·q` 或 `pq` 表示 AND，`p+q` 表示 OR，`p'` 表示 NOT；`0,1` 分别表示 F,T。

**Explanation：** `+`、`·` 不是普通加乘法。例如 `1+1=1`。常用法则有 absorption：`x+xy=x`，以及 combining opposites：`xy+xy'=x`。

**Example：** `xy+xy'=x(y+y')=x·1=x`。两个项唯一差异是 y 的真假，因此 y 被消去。

### Boolean Algebras Beyond Truth Values

**Definition：** 一个集合若配有 `0,1, +, ·, '` 并满足布尔代数规律，就是 Boolean algebra；它不必是 `{0,1}` 本身。

**Explanation：** 集合操作和位向量操作也遵循同一结构：这解释了逻辑、电路与集合论为何可用相似的化简规律。

**Example：** 在 `Pow(S)` 中，`0=∅`、`1=S`、`X+Y=X∪Y`、`X·Y=X∩Y`、`X'=S\X`。例如若 `S={a,b,c}`，`{a}+{b,c}={a,b,c}`。

### CNF and DNF

**Definition：** literal 是变量 `p` 或它的否定 `p'`。CNF（conjunctive normal form）最外层为 AND，每个 clause 是 literals 的 OR；DNF（disjunctive normal form）最外层为 OR，每个 clause 是 literals 的 AND。

**Explanation：** 名称看最外层运算。任何 Boolean expression 都能转为等价的 CNF 和 DNF：先消去 `⇒`，用 De Morgan 推进否定，最后用分配律整理。

**Example：** `(p+q)(p'+r)` 是 CNF；`p+q'r` 是 DNF。`p+q'` 同时是 CNF（一个 OR clause）和 DNF（两个单 literal clauses）。

### Canonical DNF

**Definition：** canonical DNF 从真值表的所有输出为 1 的行构造：值为 1 的变量原样写，值为 0 的变量取否定；每一行用 AND 连接，所有真行再用 OR 连接。

**Explanation：** 它提供每个布尔函数的统一表达方式，但可能比实际最短表达式长得多。

**Example：** 若 E 在 `(x,y)=(0,0),(1,0),(1,1)` 时为 1，则 canonical DNF 为 `x'y'+xy'+xy`；它可化简为 `x+y'`。

### Karnaugh Map

**Definition：** Karnaugh map（卡诺图）是适用于 2 至 4 个变量的图形化布尔化简法。把函数为 1 的真值表格子标出来，再用尽量少且尽量大的矩形覆盖它们。

**Explanation：** 每个矩形的格子数必须是 1、2、4、8 等 2 的幂，不能覆盖 0；边缘可相接。矩形合并能消去在其中同时出现真/假的变量。

**Example：** 两个相邻格对应 `xy` 和 `xy'`，可合并为 `x`，因为 `xy+xy'=x(y+y')=x`。

### Isomorphism

**Definition：** 若两个 Boolean algebras 间存在一一对应，且该对应保持 `0,1,+,·,'`，则它们 isomorphic（同构），记作 `B₁≅B₂`。

**Explanation：** 同构表示元素名称不同，但运算结构完全一样；研究一种结构即可理解另一种。

**Example：** `Pow({a,b,c})≅B³`。子集 `{a,c}` 对应向量 `(1,0,1)`；集合并、交、补分别对应按位 OR、AND、NOT。

#### 第三周：函数与关系（Functions and Relations）

### 函数、定义域、陪域与像

**定义：** `f:S→T` 是函数，表示每个 `s∈S` 都对应唯一一个 `t∈T`。`S=Dom(f)` 为定义域，`T=Codom(f)` 为陪域，`Im(f)={f(x):x∈S}` 为像。

**解释：** 每个输入必须有一个输出，同一输入不能有两个输出；不同输入可共用输出。永远有 `Im(f)⊆Codom(f)`：陪域是允许输出，像是实际输出。

**用法 / 方法：** 判断关系是否为函数：每个定义域元素必须恰好有一个输出。求 image 时要计算实际输出，不能直接抄陪域。

**例子：** `length:{a,b}*→N`，`length(aba)=3`、`length(λ)=0`，且 `Im(length)=N`。

### 输出是集合的函数

**定义：** `Σ={a,b}`，`g:N→Pow(Σ*)`，`g(n)={ω∈Σ*:length(ω)≤n}`。

**解释：** g 的一个输出是一整组 strings，所以 codomain 是 `Pow(Σ*)`。

**用法 / 方法：** 依长度取并集：`g(n)=Σ⁰∪Σ¹∪...∪Σⁿ=Σ≤n`。

**例子：** `g(2)={λ,a,b,aa,ab,ba,bb}`，`|g(n)|=2⁰+...+2ⁿ=2ⁿ⁺¹-1`。`{λ,a}` 不在 `Im(g)`，因为它漏掉同长度的 b。

### 复合、迭代与恒等函数

**定义：** 当 `Im(f)⊆Dom(g)`，`(g∘f)(x)=g(f(x))`。若 `f:S→S`，可写 `f²=f∘f`。`Id_S:S→S` 满足 `Id_S(x)=x`。

**解释：** `g∘f` 是先 f、后 g；复合有结合律但通常不可交换。恒等函数不改变输入：`g∘Id_S=g`。

**用法 / 方法：** 写类型图 `S --f--> T --g--> U`，从最里面开始代入。

**例子：** `f(n)=n+1`、`g(n)=max(0,n-1)`。`g∘f=Id_N`，但 `(f∘g)(0)=1`，所以不可交换。

### 偏函数、满射、单射与反函数

**定义：** `f:S⇀T` 是只在 `S'⊆S` 定义的偏函数。满射为 `Im(f)=T`；单射为 `f(x)=f(y)⇒x=y`。反函数存在当且仅当 f 同时单射、满射。

**解释：** 满射问“有没有漏掉输出”，单射问“有没有输入碰撞”。有限集合上的 `f:S→S` 中，两者等价；无限集合不一定。

**用法 / 方法：** 证明满射：给任意输出 t 构造输入 x。反驳满射：找遗漏的 t。证明单射：从 `f(x)=f(y)` 推出 `x=y`；反驳：找不同输入同输出。

**例子：** `n↦n+1:N→N` 单射但不满射（缺 0）；`n↦max(0,n-1)` 满射但非单射，因为 `g(0)=g(1)=0`。

### 反函数与逆像

**定义：** `f⁻¹:T→S` 是反函数；对 `B⊆T`，逆像 `f←(B)={s∈S:f(s)∈B}`。

**解释：** 反函数必须唯一恢复输入；逆像只列出所有对应输入，所以即使没有反函数也能求。

**用法 / 方法：** 求反函数：设 `y=f(x)`，解出 x 并代回验证。求逆像：找全部使输出落入 B 的输入。

**例子：** `length←(2)={aa,ab,ba,bb}`，所以 length 没有反函数。`f(x,y)=(x+y,x-y)` 的反函数是 `f⁻¹(a,b)=((a+b)/2,(a-b)/2)`。

## 矩阵（Matrices）

### 矩阵、转置与对称

**定义：** `m×n` matrix 有 m 行、n 列；`Aᵀ` 满足 `(Aᵀ)ᵢⱼ=aⱼᵢ`。若 `Aᵀ=A`，称为 symmetric matrix。

**解释：** 转置交换行和列；矩阵广泛用于优化、图形/视觉、密码学、搜索、机器学习。

**例子：** `[[1,2],[2,3]]` 转置后不变，故对称；`[[1,2],[3,4]]` 不对称，因为 `2≠3`。

### 加法、标量乘法与矩阵乘法

**定义：** 同尺寸矩阵逐格相加；`cA` 逐格乘 c。`(m×n)(n×p)=(m×p)`，且 `(AB)ᵢₖ=Σⱼaᵢⱼbⱼₖ`。

**解释：** 矩阵乘法为左矩阵一行乘右矩阵一列；内侧维度必须匹配，且通常 `AB≠BA`。

**用法 / 方法：** 先检查形状，再逐格计算 row × column。

**例子：** `[[1,2],[3,4]][[5,6],[7,8]]=[[19,22],[43,50]]`，左上角是 `1·5+2·7=19`。

## 关系（Relations）

### n 元关系、二元关系与关系矩阵

**定义：** n 元关系是 `R⊆S₁×...×Sₙ`；二元关系为 `R⊆S×T`，可写 `(x,y)∈R` 或 `xRy`。

**解释：** relation 不要求每个输入有唯一输出，适合表示多对多联系。

**使用场景：** databases、graphs、orderings、程序规格。

**例子：** 选课 `E={(s,c):学生 s 修读 c}⊆Students×Courses`。函数作为关系时，每一行恰有一个点；关系矩阵的行是 S，列是 T。

### 特殊关系

**定义：** 在 S 上：identity `E={(x,x):x∈S}`；empty relation 为 `∅`；universal relation 为 `U=S×S`。

**例子：** S=`{a,b}` 时，`E={(a,a),(b,b)}`，而 U 还包括 `(a,b),(b,a)`。

### 五种关系性质

**定义：**

```text
reflexive:       ∀x,(x,x)∈R
antireflexive:   ∀x,(x,x)∉R
symmetric:       xRy⇒yRx
antisymmetric:   xRy 且 yRx ⇒ x=y
transitive:      xRy 且 yRz ⇒ xRz
```

**解释：** 反自反不等于“非自反”；反对称不等于“非对称”。一个关系可同时 symmetric 与 antisymmetric，例如 identity。

**用法 / 方法：** 自反/反自反看对角线；对称检查每个 pair 的反向；反对称找不同元素的双向 pair；传递找 `x→y→z` 却缺 `x→z` 的反例。

**例子：** `<` 是 antireflexive、antisymmetric、transitive，但非 symmetric。`≠` 是 symmetric、antireflexive，但非 transitive：`1≠2,2≠1`，却 `1≠1` 不成立。

### 偏序、全序与等价关系

**定义：** partial order = reflexive + antisymmetric + transitive；total order 还要求任意两元素可比较；equivalence relation = reflexive + symmetric + transitive。

**例子：** `≤` 是全序；`⊆` 是偏序（`{a}` 与 `{b}` 不可比较）；同余 mod n 是等价关系。

### 逆关系、关系像与关系复合

**定义：** `R←={(t,s):(s,t)∈R}`。`R(A)={t:(s,t)∈R for some s∈A}`。若 `R₁⊆S×T,R₂⊆T×U`，则 `R₁;R₂={(s,u):存在 t, sR₁t 且 tR₂u}`。

**解释：** 逆关系反转 ordered pairs；关系像收集从子集可达的元素；复合是经由中间对象走两步。

**用法 / 方法：** 逆关系逐对反转；求 R(A) 收集所有第二项；求复合列全部路径 `s→t→u`。

**例子：** E 为 student→course，L 为 course→time，则 `E;L` 为 student→time。`R₁={(a,b)}`、`R₂={(b,c)}` 各自传递，但并集不传递，因为缺少 `(a,c)`。

## Week 4：Equivalence and Order Relations（等价关系与序关系）

依据：COMP9020 26T3 Week 4，Michael Thielscher，week4.pdf，共 62 页。教材指引：R & W 第 3 章 §3.4–3.5、第 11 章 §11.1–11.2；配套 Problem Set 4。

已按知识点合并重复的题目/答案渐显页，保留全部实质内容及练习。每节注明 PDF 页码；为帮助理解添加的例子、证明和严谨性说明属于学习补充。记号：`N={0,1,2,...}`，`P={1,2,...}`，`λ` 为空字符串；一般偏序用 `≼`，对应严格序用 `≺`。

### 1. 本周必需的关系性质（第 2、27、29、32–33 页）

**定义：** 集合 S 上的二元关系是 `R⊆S×S`，`xRy` 等同于 `(x,y)∈R`。

| 性质                   | 定义（变量均在 S 中）      | 通俗解释          |
| -------------------- | ----------------- | ------------- |
| Reflexive，自反，R       | `∀x，xRx`          | 每个元素与自己有关     |
| Symmetric，对称，S       | `xRy ⇒ yRx`       | 有去就有回         |
| Antisymmetric，反对称，AS | `xRy 且 yRx ⇒ x=y` | 不同元素不能双向有关    |
| Transitive，传递，T      | `xRy 且 yRz ⇒ xRz` | 两步能接上，必须有直达关系 |
| Linear，可比较，L         | `∀x,y，xRy 或 yRx`  | 任意两个元素都能比较    |

**用途：** 判断一个关系是否属于等价关系、偏序或全序。

**例子：** 整数上的“同奇偶”满足 R、S、T；通常的 `≤` 满足 R、AS、T、L。

**易混淆：** AS 不是“不是 S”。恒等关系 `{(x,x):x∈S}` 同时对称、反对称。判断传递性时，前提的两条关系必须都在所讨论的关系里；没有任何两步链时，传递性可以空真。

### 2. 等价关系 Equivalence Relation（第 2–3 页）

**定义：** 同时满足自反、对称、传递的关系，称为等价关系，常记作 `∼`。

\[
\text{Equivalence relation}=R+S+T.
\]

**解释：** 按某项标准，把不同对象视为“同一类”；不要求对象本身完全相等。

**用途：** 分类、去重、按共同属性分组；把不同表示合并为同一数学对象。

**例子：** 在 Z 上，`m∼n ⇔ m mod 2=n mod 2`。每个整数与自己同奇偶；同奇偶是双向的；m 与 n 同奇偶且 n 与 k 同奇偶，则 m 与 k 同奇偶。因此是等价关系。

**证明方法：** 分别证明 R、S、T，不能只举几个相等价的例子。

### 3. 等价类、代表元、划分与商集（第 2–3 页）

**定义：** s 的等价类是所有与 s 等价的元素组成的集合：

\[
[s]_R=\{t\in S:tRs\}.
\]

类中的任一元素都可作 representative（代表元）。集合 S 的 partition（划分）是由非空、两两不交的子集组成、且并集为 S 的集合族。全部不同等价类组成商集：

\[
S/R=\{[s]_R:s\in S\}.
\]

**解释：** S 是所有学生；等价类是一个班；代表元是班里任选的一名学生；商集是“所有班级组成的集合”。

**用途：** 从具体对象转向类别，避免对同类对象重复处理。

**例子：** 模 3 同余把 Z 分成：

\[
[0]=\{3k:k\in\mathbb Z\},\quad
[1]=\{3k+1:k\in\mathbb Z\},\quad
[2]=\{3k+2:k\in\mathbb Z\}.
\]

`[0]=[3]=[6]`，不同写法表示同一个类，而不是三个不同的类。

**重要性质：**

\[
s\sim t\iff[s]=[t],\qquad
s\not\sim t\iff[s]\cap[t]=\varnothing.
\]

每个元素恰好属于一个类。若两个类有共同元素 u，由对称性和传递性可得两类代表元等价，所以两个类相同。

**反方向：** 任一划分都定义一个等价关系：两个元素相关，当且仅当它们属于同一个块。因此“等价关系”和“划分”一一对应。

**记号澄清：** PPT 用 `[S]` 表示类的集合，但 S 与 `[S]` 一般不是同一个集合。严谨地写：

\[
S=\bigcup_{C\in S/R}C,
\]

其中不同的 C 两两不交。若按所有 `s∈S` 写 `[s]`，会重复列出同一个类，不能把这些重复项当成互不相交的不同块。PPT 第 2 页关系定义中的有序对应属于 `Z×Z`。

### 4. 自然映射 Natural Map（第 4–5 页）

**定义：** 将元素送到它所在等价类的函数：

\[
\nu:S\to S/R,\qquad\nu(s)=[s].
\]

**解释：** 输入一个对象，输出它的“类别标签”；这个标签本身是一个集合。

**用途：** 把原问题投影到类别层面，例如把任意整数映射到余数类。

**例子：** 模 3 时，`ν(4)=[1]=ν(7)`。

**课件练习：** ν 总是 onto（满射），因为每个等价类都非空，任选其中一个元素就能映射到该类。ν 是 1–1（单射），当且仅当每个类都是单元素集，也就是：

\[
x\sim y\iff x=y.
\]

注意“恒等关系”是关系集合 `{(s,s):s∈S}`；ν 的输出是 `[s]`，不能直接把 ν 写成数值上的 `ν(s)=s`。

### 5. 函数诱导的等价关系与原像 Fibre（第 6–7 页）

**定义：** 任意函数 `f:S→T` 都在 S 上诱导等价关系：

\[
x\sim y\iff f(x)=f(y).
\]

点 t 的原像（纤维）为 `f⁻¹({t})={s∈S:f(s)=t}`，PPT 写作 `f←(t)`。所有非空纤维构成 S 的划分。

**解释：** 把“得到相同输出”的输入分为一组。因为输出的相等关系满足 R、S、T，所以诱导关系也满足这三个性质。

**用途：** 按函数值分类，例如按余数、长度、成绩等级分组。

**例子：** `f:{1,2,3,4}→{0,1,2}`，`f(n)=n mod 2`。纤维分别为 `{2,4}`、`{1,3}`、`∅`；划分只包含前两个非空集合。

**课件练习：** 对每个 `t∈T` 都有 `f⁻¹({t})≠∅`，当且仅当 f 满射。原像不要求 f 可逆，不是“逆函数”的同义词。

### 6. 同余关系与 Zₙ（第 8–9 页）

**定义：** 对正整数 n，

\[
a\equiv b\pmod n
\iff a\bmod n=b\bmod n
\iff n\mid(a-b).
\]

同余是 Z 上的等价关系。`Zₙ` 表示模 n 的余数类，通常用代表元集合 `{0,1,...,n−1}` 计算。

**解释：** 两个整数相差整整若干圈，在 n 格循环中落到同一位置。

**用途：** 时钟、周期计算、循环编号；课件指出其在编码理论和密码学中的重要性。

**例子：** `17≡2 (mod 5)`，因为 `17−2=15` 能被 5 整除；`−1≡4 (mod 5)`。

**易混淆：** `a mod n` 是一个余数；`a≡b (mod n)` 是两个整数之间的关系。普通整数中 `17≠2`，但它们属于同一个模 5 余数类。

### 7. 模运算、负元、逆元与环（第 9–12 页）

**定义：** 本节取 `n≥2`。在 Zₙ 中，加法和乘法先按整数计算，再取模：

\[
a+_n b=(a+b)\bmod n,\qquad
a\cdot_n b=ab\bmod n.
\]

加法负元 `−a` 满足 `a+(−a)=0`；乘法逆元 `a⁻¹` 满足 `a·a⁻¹=1`，等式均在 Zₙ 中理解。

**解释：** 负元把加法“抵消回 0”；逆元把乘法“抵消回 1”。除以 a 意味着乘以 `a⁻¹`。

**用途：** 模方程求解、周期内的运算、可逆变换。

**PPT 的 Z₅ 运算表：**

| +₅  | 0   | 1   | 2   | 3   | 4   |
| --- | --- | --- | --- | --- | --- |
| 0   | 0   | 1   | 2   | 3   | 4   |
| 1   | 1   | 2   | 3   | 4   | 0   |
| 2   | 2   | 3   | 4   | 0   | 1   |
| 3   | 3   | 4   | 0   | 1   | 2   |
| 4   | 4   | 0   | 1   | 2   | 3   |

| ×₅  | 0   | 1   | 2   | 3   | 4   |
| --- | --- | --- | --- | --- | --- |
| 0   | 0   | 0   | 0   | 0   | 0   |
| 1   | 0   | 1   | 2   | 3   | 4   |
| 2   | 0   | 2   | 4   | 1   | 3   |
| 3   | 0   | 3   | 1   | 4   | 2   |
| 4   | 0   | 4   | 3   | 2   | 1   |

| a   | 0   | 1   | 2   | 3   | 4   |
| --- | --- | --- | --- | --- | --- |
| −a  | 0   | 4   | 3   | 2   | 1   |
| a⁻¹ | 不存在 | 1   | 3   | 2   | 4   |

**重要条件（补充）：**

\[
a^{-1}\text{ 在 }\mathbb Z_n\text{ 中存在}\iff\gcd(a,n)=1.
\]

若模数 p 是质数，则每个非零元素都有逆元；合数模数下，只有与模数互质的元素可逆。即使 p 是质数，也不能除以 0。

**代数背景：** PPT 称 `(Zₙ,+,·,0,1)` 为 ring（环）：加法满足交换律、结合律，有 0 和负元；乘法满足结合律、有 1，并对加法满足分配律。这里乘法也满足交换律。质数模数下，每个非零元素可逆，进一步构成 field（域，补充术语）。

**练习 3.5.6：** 在 Z₇ 中，`5+6=4`，`4·4=2`；任意 k 满足 `0+k=k`、`1·k=k`。这些等式须在相应模运算环境中理解。

### 8. 模方程求解（第 13–15 页）

**定义与方法：** 加法方程通过加负元求解；乘法方程 `ax=b` 只有在 a 可逆时，才能直接写 `x=a⁻¹b`。

**解释：** 普通除法不能照搬到模运算；先检查除数有没有逆元。

**用途：** 求循环系统中未知量，判断方程是否有解、解是否唯一。

**PPT 全部例题：**

| 环境  | 方程      | 计算与结果                     |
| --- | ------- | ------------------------- |
| Z₅  | `2+x=1` | `x=1−2≡4`                 |
| Z₅  | `2x=1`  | `2·3≡1`，所以 `x=3`          |
| Z₅  | `2x=3`  | `x=3·2⁻¹=3·3≡4`           |
| Z₆  | `5+x=1` | `x=1−5≡2`                 |
| Z₆  | `5x=1`  | `5·5=25≡1`，所以 `x=5`       |
| Z₆  | `2x=1`  | `2x mod 6` 只能为 0、2、4，因此无解 |

**易错点：** PPT 最后一题写 undefined，准确区分是“2 的逆元不存在，因此方程 `2x=1` 无解”。非可逆系数不意味着所有右端都无解：在 Z₆ 中，`2x=2` 有 `x=1,4` 两个解。不能直接约掉 2。

### 9. 几何中的等价类：粘合边界（第 16–17 页）

**定义：** 指定某些点等价，再把每个等价类视为一个点，得到粘合后的空间。

**解释：** 纸上原本不同的位置，在新空间里被当成同一个位置。

**用途：** 用平面矩形描述曲面；理解周期边界和商空间的基本思想。

**PPT 例子：** 矩形左上、左下、右上、右下分别是 a、b、c、d。

- 将左边 `[a,b]` 与右边 `[c,d]` 按同方向对应粘合，得到圆柱面。内部点的类只有 1 个元素；左右边界对应点的类有 2 个元素。
- 再将上边 `[a,c]` 与下边 `[b,d]` 同方向粘合，得到 torus（环面）。四个角 `{a,b,c,d}` 构成同一个含 4 个元素的等价类。
- 将 `[a,b]` 与反方向的 `[d,c]` 粘合，得到 Möbius strip（莫比乌斯带），是单侧曲面。
- 在此基础上再粘合另一对边，得到 Klein bottle（克莱因瓶）。它不能在三维空间中无自交地嵌入；PPT 图中的穿插来自三维展示方式。

**易错点：** 每个内部点各自成类，不是把所有内部点粘成一类。

### 10. 按平方余数分类：练习 3.6.6（第 18–19 页）

**定义：** 在 `S={1,...,7}` 上定义 `m∼n ⇔ m²≡n² (mod 5)`。

**解释与用途：** 按“平方后的模 5 余数”分类；展示函数如何诱导等价关系，而不是直接按原数余数分组。

**计算：**

| m        | 1   | 2   | 3   | 4   | 5   | 6   | 7   |
| -------- | --- | --- | --- | --- | --- | --- | --- |
| m² mod 5 | 1   | 4   | 4   | 1   | 0   | 1   | 4   |

因此全部不同等价类是：

\[
[1]=\{1,4,6\},\quad[2]=\{2,3,7\},\quad[5]=\{5\}.
\]

**证明：** 令 `f(m)=m² mod 5`，则 `m∼n ⇔ f(m)=f(n)`，由第 5 节可知它满足 R、S、T。

PPT 还指出：

\[
m^2\equiv n^2\pmod5
\iff m\equiv n\pmod5\ \text{或}\ m\equiv-n\pmod5.
\]

因为 `5|(m−n)(m+n)`，且 5 是质数，必整除其中一个因子。不能把这个推理任意推广到合数模数。

### 11. 等价类上函数的良定义性 Well-defined（第 20–21 页）

**定义：** 若想用代表元公式 `g(s)` 定义 `Φ([s])=g(s)`，必须满足：

\[
s\sim t\implies g(s)=g(t).
\]

同时 g 必须对所有代表元有定义，且输出属于目标集合。

**解释：** 同一类换一个代表元，答案必须不变。否则同一个输入“类”会得到不同输出，就不是函数。

**用途：** 在余数类、分数的不同表示、商集上定义函数或运算。

**正例：** 对按模 4 划分的自然数，定义 `Φ([n]₄)=n mod 2`。若 `n≡m (mod 4)`，则 `4|(n−m)`，从而 `2|(n−m)`，输出相同。因此良定义，例如 0、4、8 都输出 0。

**反例：** 尝试定义 `Ψ([n]₃)=n mod 5`。虽然 `[0]₃=[3]₃`，但 `0 mod 5=0`，`3 mod 5=3`，因此不良定义。

**易错点：** “任选代表元”要求结果与选择无关；若明确规定总选标准余数，那是在定义另一条带有固定选择规则的函数，不能据此证明原来的任意代表元公式良定义。

### 12. 用“或”组合关系：练习 3.6.10（第 22–25 页）

**定义：** 定义域是 `N×N`；其中的元素本身是有序对：

\[
(m,n)R(p,q)\iff m\equiv p\pmod3\ \text{或}\ n\equiv q\pmod5.
\]

因此 `R⊆(N×N)×(N×N)`，也可将四个坐标看成 N⁴ 中的元素。

**解释：** 第一坐标符合标准，或者第二坐标符合标准，就算相关。

**用途：** 检查多个匹配条件以 OR 合并后，是否仍能形成一致的分类。

**结论：** 自反、对称，但不传递，所以不是等价关系。

**具体反例：** 取 `A=(1,1)`、`B=(2,1)`、`C=(2,2)`。A R B 因为第二坐标相同；B R C 因为第一坐标相同；但 A 与 C 的第一坐标模 3 不同、第二坐标模 5 也不同，所以 `A 不 R C`。

**易错点：** 两段关系可能依赖 OR 的不同分支，不能将它们接成同一种传递链。这也解释了两个等价关系的并集为什么不一定是等价关系。

### 13. 全序 Total Order 与不同的序结构（第 26–28 页）

**定义：** 全序满足自反、反对称、传递，且任意两个元素可比较：

\[
\text{Total order}=R+AS+T+L.
\]

**解释：** 所有元素都能排成一条前后关系明确的队列。

**用途：** 排名、按键排序、比较数值或字典中的词。

**例子：** N、Z、Q、R 上通常的 `≤` 都是全序。

**有限情形与同构：** n 个元素的全序都具有 `x₁<x₂<...<xₙ` 的结构。同构是保持顺序的双射：`x≤y ⇔ h(x)≤h(y)`。例如 `{2,5,9}` 与 `{a,b,c}`（规定 `a<b<c`）按第 1、2、3 位对应即可。这里必须比较相同元素数的有限全序。

**无限情形：**

| 集合及通常次序           | 特点与例子                      |
| ----------------- | -------------------------- |
| N                 | 离散，有最小元 0，没有最大元            |
| Z                 | 离散，无最小元、最大元；相邻整数间没有其他整数    |
| Q                 | 稠密：若 `p<q`，则 `p<(p+q)/2<q` |
| `[a,b]`，`a<b`     | 最小元 a、最大元 b                |
| `(a,b]`           | 无最小元，最大元 b                 |
| `[a,b)`           | 最小元 a，无最大元                 |
| `[0,1]∪[2,3]∪...` | 每段内部稠密，但 1 与 2 之间没有集合内的元素  |

**易混淆：** 全序不代表一定有首尾元素；“稠密”说的是任意两个不同元素之间还有元素。

### 14. 偏序 Poset 与严格序（第 29 页）

**定义：** 偏序 `≼` 满足 R、AS、T，不要求 L；`(S,≼)` 称为 partially ordered set，简称 poset。

与它对应的严格序定义为：

\[
x\prec y\iff x\preceq y\text{ 且 }x\ne y.
\]

**解释：** 有些元素能比较，有些没有先后关系；严格序把“等于自己”的情况去掉。

**用途：** 集合包含关系、整除关系、任务依赖关系。

**例子：** `({1,2,3,6}, |)` 是偏序。`2|6`，但 2 与 3 互不整除，所以不是全序。`(Pow(S),⊆)` 也是偏序。

**严格序的性质：** `x≺x` 永不成立，即反自反；它传递且不对称：`x≺y ⇒ 非(y≺x)`。若来自全序，则任意不同的 x、y 满足 `x≺y` 或 `y≺x`。

**PPT 术语说明：** 第 29 页把这里的严格序称作 quasi-order。本笔记按它给出的公式理解为“严格序”，以免与其他资料中把 quasi-order 用作“预序”的习惯混淆。严格序的可比较条件必须排除 `x=y`，不能直接照搬非严格全序的 L。

### 15. 子串关系是偏序：练习 11.1.8（第 30–31 页）

**定义：** 对 `u,v∈Σ*`，定义：

\[
u\preceq v\iff v=\alpha u\beta\quad(\alpha,\beta\in\Sigma^*).
\]

即 u 是 v 的连续子串。

**解释与用途：** 比较字符串的包含关系，可用于文本片段、模式匹配和结构包含分析。

**例子：** `ab≼cabc`，因为 `cabc=c·ab·c`；但 `ac` 不是 `abc` 的连续子串。

**证明：**

- R：`u=λuλ`，所以 `u≼u`。
- AS：若互为子串，则 `|u|≤|v|` 且 `|v|≤|u|`；长度相同，包在外面的字符串只能为空，因此 `u=v`。
- T：若 `v=αuβ`、`w=γvδ`，则 `w=(γα)u(βδ)`，所以 `u≼w`。

**易错点：** substring 必须连续，subsequence 可以跳过字符；题目讨论前者。若字母表含 a、b 两个不同符号，则 a 与 b 不可比，因此该偏序一般不是全序。

### 16. 四种关系的性质：练习 11.6.16（第 32–33 页）

**定义：** 在正整数 P 上，分别定义 `mR₁n⇔m|n`、`mR₂n⇔|m−n|≤2`、`mR₃n⇔2|(m+n)`、`mR₄n⇔3|(m+n)`。

**解释与用途：** 分别比较“整除”“距离近”“和的奇偶”“和能否被 3 整除”，练习按定义分类，而不是凭关系外观猜测。

| 性质     | R₁  | R₂  | R₃  | R₄  |
| ------ | --- | --- | --- | --- |
| 自反 R   | 是   | 是   | 是   | 否   |
| 对称 S   | 否   | 是   | 是   | 是   |
| 反对称 AS | 是   | 否   | 否   | 否   |
| 传递 T   | 是   | 否   | 是   | 否   |
| 等价关系   | 否   | 否   | 是   | 否   |
| 偏序     | 是   | 否   | 否   | 否   |

**例子与理由：**

- R₁：`2|4` 而 `4∤2`，故不对称；正整数互相整除必相等，故反对称；整除链可相乘，故传递。若定义域换成全部整数，`2|−2` 且 `−2|2`，反对称性会失败。
- R₂：1 与 2 双向有关但不相等，故不反对称；`1R₂3`、`3R₂5`，但 `1 不 R₂ 5`，故不传递。
- R₃：`m+n` 为偶数等价于 m、n 同奇偶，是等价关系；1 与 3 说明它不反对称。
- R₄：`3∤(1+1)`，故不自反；1 与 2 双向有关，故不反对称；`1R₄2`、`2R₄1`，但 `1 不 R₄ 1`，故不传递。反例中允许首尾元素相同。

### 17. Hasse Diagram（哈斯图）（第 34 页）

**定义：** 有限偏序用覆盖关系画图：若 `x≺y` 且不存在 z 使 `x≺z≺y`，则从下方 x 向上方 y 画一条边。

**解释：** 只画“紧挨着的上一级”；省略自环，以及能通过向上路径推出来的关系。

**用途：** 直观看出可比较性、极小/极大元素、上下界和拓扑排序。

**PPT 例子：** 24 的正因数集合：

\[
D_{24}=\{1,2,3,4,6,8,12,24\},\quad x\preceq y\iff x\mid y.
\]

覆盖边由下到上为：

```text
1—2，1—3；
2—4，2—6，3—6；
4—8，4—12，6—12；
8—24，12—24。
```

**画法：** 先确定关系，去掉 `(x,x)`，再去掉可以由中间点连接的边。例如不画 `1—4`，因为 `1≺2≺4`。

**易错点：** 两点在图上的高低位置本身不保证可比，必须存在沿边一直向上的路径。线段交叉处若没有标出的顶点，不是新增元素。

### 18. 拓扑排序 Topological Sort（第 35 页）

**定义：** 将偏序扩展为与它一致的全序：

\[
a\preceq b\implies a\leq_{\text{排序}}b.
\]

**解释：** 原来规定必须在前的仍然在前；原本不可比较的元素也被安排先后。

**用途：** 先修课安排、任务执行顺序、编译依赖排序。

**PPT 例子：** 图中的覆盖关系为 `a≺b`、`a≺e`、`b≺c`、`e≺c`、`e≺f`、`c≺d`、`f≺d`。合法排序包括：

```text
a, b, e, c, f, d
a, e, b, f, c, d
a, e, f, b, c, d
```

**构造方法（补充）：** 每次选剩余偏序的一个极小元，输出后删去它；重复直到结束。每个非空有限偏序都有极小元，所以过程可以完成。

**易错点：** 排序通常不唯一；b 与 e 在某个排序中出现先后，不表示原偏序规定 `b≼e`。

### 19. 极小/极大与最小/最大（第 36–38 页）

**定义：** 在偏序 S 中：

| 概念                     | 条件         | 直观含义      |
| ---------------------- | ---------- | --------- |
| minimal，极小元 m          | 不存在 `x≺m`  | 没有人严格在它下面 |
| maximal，极大元 m          | 不存在 `m≺x`  | 没有人严格在它上面 |
| minimum/least，最小元 m    | `∀x∈S，m≼x` | 它小于等于所有人  |
| maximum/greatest，最大元 m | `∀x∈S，x≼m` | 它大于等于所有人  |

**用途：** 区分局部无法继续改善的候选，与能和所有对象比较的全局最优对象。

**PPT 例子：** `Pow({a,b,c})` 按包含排序，最小元为 `∅`，最大元为 `{a,b,c}`。删去 `{a,b,c}` 后，`{a,b}`、`{a,c}`、`{b,c}` 都是极大元，但没有最大元。

**重要性质：** 每个非空有限偏序都有极小元和极大元；它们可以不唯一。最小元和最大元若存在必唯一；例如 m、n 都最小，则 `m≼n` 且 `n≼m`，由反对称性得 `m=n`。

**严谨性提醒：** PPT 的“minimum = unique minimal”在有限非空偏序中成立，不能不加条件用于无限偏序。例如把一个孤立元素 m 与整数链 Z 放在一起，规定 m 与所有整数不可比。m 是唯一极小元，但它不小于任何整数，因此不是最小元。

### 20. 上界、下界、上确界 lub 与下确界 glb（第 37–42 页）

**定义：** 给定偏序 S 及子集 `A⊆S`：

\[
U(A)=\{u\in S:\forall a\in A,\ a\preceq u\},
\quad L(A)=\{l\in S:\forall a\in A,\ l\preceq a\}.
\]

上确界 `lub(A)=sup(A)` 是 U(A) 的最小元；下确界 `glb(A)=inf(A)` 是 L(A) 的最大元。

**解释：** 上确界是所有共同上界中最小的；下确界是所有共同下界中最大的。

**用途：** 找最紧的共同限制；在整除序中求共同倍数/因数，在包含序中合并/提取共有信息。

**例子：** 在 `D₂₄` 的整除序中，`lub({4,6})=12`，`glb({4,6})=2`。这里“大、小”按整除关系判断。

**如何证明 `u=lub(A)`：** 先证 u 是上界，再证对每个上界 v 都有 `u≼v`；glb 的证明方向相反。仅找到一个上界还不够。

**与最大元的区别：** 上下确界必须属于环境 S，但不必属于 A。若 `lub(A)∈A`，它就是 A 的最大元；反之亦然。

**练习 11.1.5 全部结果：** 在 `(R,≤)` 中：

- 它是格，因为任意 a、b 的 lub 是 `max(a,b)`，glb 是 `min(a,b)`。
- 正实数集 `R>0` 没有上界：任何候选上界都能被一个更大的正实数超过。
- `lub({x:x<73})=73`，但该集合没有最大元。
- `lub({x:x≤73})=73`，且 73 是该集合的最大元。
- `{x:x²<73}=(-√73,√73)`，所以其 lub 为 `√73`、glb 为 `−√73`；两者都不属于这个开区间。

### 21. 格 Lattice 与“不存在最小上界”（第 37–39 页）

**定义：** 若偏序中每对元素都有 lub 和 glb，则称为格。常写：

\[
a\vee b=\operatorname{lub}\{a,b\},\qquad
a\wedge b=\operatorname{glb}\{a,b\}.
\]

**解释：** 任意两项都能找到唯一的最小共同上界、最大共同下界。

**用途：** 统一理解集合并交、共同倍数/因数、信息的合并与共同部分；也与前面学过的布尔代数连接。

**例子与反例：**

| 偏序                     | 是格吗 | 理由                                 |
| ---------------------- | --- | ---------------------------------- |
| `(Pow(X),⊆)`           | 是   | `A∨B=A∪B`，`A∧B=A∩B`                |
| 24 的全部正因数，整除序          | 是   | join 为 lcm，meet 为 gcd，且结果仍是 24 的因数 |
| `{1,2,3}`，整除序          | 否   | 2、3 没有共同上界                         |
| `{2,3,6}`，整除序          | 否   | 2、3 没有共同下界                         |
| `{1,2,3,12,18,36}`，整除序 | 否   | 2、3 有上界，但没有最小上界                    |

**最后一个反例的关键：** `{2,3}` 的上界是 `{12,18,36}`。12、18 都是极小上界，但互不整除；没有任何一个上界小于等于所有其他上界，所以没有 lub。数值上 `12<18` 不代表整除序中 `12≼18`。

**易错点：** 不能取环境中不存在的 6 当 lub。只有在相应集合对 gcd/lcm 封闭时，才可直接套用这些公式。

**有限集合结论：** 两两有 lub/glb 可通过反复合并推广到每个非空有限子集。空集是例外：`lub(∅)` 要求整个偏序有最小元，`glb(∅)` 要求整个偏序有最大元。

### 22. 无限情形、有限子集族 F(N) 与无限子集族 I(N)（第 40、43–46 页）

**定义：**

\[
F(\mathbb N)=\{A\subseteq\mathbb N:A\text{ 有限}\},\quad
I(\mathbb N)=\{A\subseteq\mathbb N:A\text{ 无限}\}.
\]

两者都按 `⊆` 排序。

**解释：** “每一对有上下确界”不保证“无限多个也有”；还要检查候选结果是否仍属于规定的集合族。

**用途：** 判断无限结构是否是格，以及能否对无限多项做合并/交集。

**例子一：整数格。** `(Z,≤)` 是格，每对整数都有 min/max；但整个 Z 没有上界也没有下界，所以没有 `lub(Z)`、`glb(Z)`。不是说每对整数没有 lub/glb。

**例子二：练习 11.1.13，F(N)。**

- 没有极大元：对每个有限 A，总能选 `n∉A`，得到更大的有限集 `A∪{n}`。
- `∅` 是最小元，也是唯一极小元。
- 每对 A、B 的 lub 为 `A∪B`，glb 为 `A∩B`；两者都有限，所以 F(N) 是格。
- 无限族 `Aₖ={0,...,k}` 的并集是 N，没有任何有限上界，因此在 F(N) 中没有 lub。
- 任意非空有限或无限集合族的交集都包含于其中任一有限成员，因此仍有限，glb 存在。

**例子三：练习 11.1.14，I(N)。**

- N 是最大元，也是唯一极大元。
- 没有极小元：从任何无限集删掉一个元素，仍是更小的无限集。
- 两个无限集的并集仍无限，所以 `lub(A,B)=A∪B`。
- 若 `A∩B` 无限，则 `glb(A,B)=A∩B`；若交集有限，则没有属于 I(N) 的共同下界。
- 例如偶数集 `2N` 与奇数集 `2N+1` 的交集为空，因此无 glb，I(N) 不是格。

**严谨性说明：** PPT 第 40 页把 I(N) 列在无限上下界讨论中，但它连“两两有 glb”都不满足，不能当作无限格的例子。上述任意并/交的论述要注意非空集合族的条件。

### 23. 良序 Well-order（第 47 页）

**定义：** 一个全序中，每个非空子集都有最小元，称为良序。

**解释：** 不论挑出哪些元素，只要挑出的集合非空，总能找到排在最前面的一个。

**用途：** 证明程序终止。若每一步都让一个取值于良序集的度量严格下降，就不可能无限执行下去。

**例子：** N 的通常次序是良序；倒计数每次令 `n←n−1`，且始终保持 `n≥0`，不可能无限下降。

PPT 还有按块排列的例子：`N₁ ⊔ N₂ ⊔ N₃ ⊔ ...`，每块内部像 N，且第一块所有元素在第二块所有元素之前，依此类推。对任何非空子集，先找它涉及的最早块，再找该块内最小元素，即得最小元。

**反例与易混淆：** Z 虽是全序却不是良序，因为 Z 本身没有最小元；`[0,1]` 虽有最小元 0，却不是良序，因为子集 `(0,1]` 没有最小元。良序不要求最大元。PPT 写“every subset”时必须补上 non-empty，空集不可能有最小元素。

### 24. 乘积序 Product Order（第 48、51 页）

**定义：** 两个偏序的笛卡尔积上，逐坐标用 AND 比较：

\[
(s,t)\preceq(s',t')\iff s\preceq_S s'\ \text{且}\ t\preceq_T t'.
\]

**解释：** 每个指标都不超过对方，整体才“不超过”对方。

**用途：** 多指标比较、资源用量、二维网格中的单调移动。

**例子：** `(1,2)≼(2,4)`，但 `(1,4)` 与 `(2,3)` 不可比，因为一个第一坐标小、另一个第二坐标小。

**为什么是偏序：** 两个坐标各自自反，得到整体自反；若两个方向都成立，则各坐标由反对称性相等，得到有序对相等；逐坐标传递得到整体传递。

**练习 11.2.4：** 即使两个因子都是全序，只要两者各有至少两个元素，乘积序也不是全序。取 `s₁<s₂`、`t₁<t₂`，则 `(s₁,t₂)` 与 `(s₂,t₁)` 不可比。

### 25. 链 Chain、极大链与长度限制（第 49–50 页）

**定义：** 偏序的一个子集若内部任意两元素可比，称为 chain（链）。极大链指不能再加入其他元素仍保持为链；最长链指元素数最多的链。

**解释：** 整个偏序未必能排成一条链，但其中的一部分可以。

**用途：** 找连续可比较的状态序列、单调路径，分析层数和最大步数。

**练习 11.2.1：** `A={1,2,3,4}`，在 `A×A` 的乘积序中，7 元素链的一个例子是：

\[
(1,1)\prec(1,2)\prec(2,2)\prec(2,3)\prec(2,4)\prec(3,4)\prec(4,4).
\]

**为什么没有 8 元素链：** 令 `r(x,y)=x+y`，其取值从 2 到 8。链每次严格上升时，至少一个坐标增加，另一个不减，因此 r 至少增加 1。只有 7 种整数值，链最多 7 个元素。

**易混淆：** 极大链不一定是最长链；本例给出的链既极大又最长。仅证明“不能给这条链加点”，通常不能证明其他链都不会更长；上述坐标和才给出全局上界。

### 26. 乘积定义中的 AND 不能随便改为 OR（第 52–53 页）

**定义：** 练习 11.2.10 尝试定义：

\[
(s,t)Q(s',t')\iff s\preceq s'\ \text{或}\ t\preceq t'.
\]

**解释与用途：** 检查“至少一项不超过”是否足以形成合法的偏序比较规则。

**结论：** 不保证是偏序；自反性保留，但反对称性和传递性可能失败。

**反对称反例：** 在通常整数次序下，`A=(1,2)`、`B=(2,1)`。A Q B 因为 `1≤2`；B Q A 因为第二坐标 `1≤2`；但 `A≠B`。

**传递反例：** 取 `A=(2,2)`、`B=(3,0)`、`C=(1,1)`。A Q B 因第一坐标 `2≤3`；B Q C 因第二坐标 `0≤1`；但 A 的两个坐标都大于 C，对应 `A 不 Q C`。

**易错点：** 每个坐标原有传递性，也不能保证不同坐标交替满足的 OR 关系传递。

### 27. 函数的逐点偏序 Pointwise Order（第 54 页）

**定义：** S 是任意集合，`(T,≼T)` 是偏序。在全部函数 `M={f:S→T}` 上定义：

\[
f\preceq g\iff\forall s\in S,\ f(s)\preceq_T g(s).
\]

**解释：** 对每一个相同输入，f 的输出都不超过 g 的输出。

**用途：** 比较函数在各输入上的数值、成本或资源消耗。

**例子：** 若 `S={a,b}`，`f(a)=1,f(b)=2`，`g(a)=2,g(b)=3`，则 `f≼g`。但输出向量 `(1,3)` 与 `(2,2)` 对应的函数不可比。

**为什么是偏序：** 自反、传递逐点继承自 T；若 `f≼g` 且 `g≼f`，则每个 s 上输出相等，由函数相等的定义得 `f=g`。

**易错点：** S 不需要排序，比较使用的是输出集合 T 的偏序。若 S 有 n 个元素，可把函数写为 n 个输出值的向量，就是多坐标乘积序。

### 28. 字典序、长度字典序与定长字典序（第 55–57 页）

**定义：** 假设字母表 Σ 已有全序。

| 名称                 | 比较规则                                  | 使用场景            |
| ------------------ | ------------------------------------- | --------------- |
| Lexicographic，字典序  | 从左到右找第一个不同字符，以该字符决定；若一个串是另一个的真前缀，短串在前 | 字典、姓名、文本排序      |
| Lenlex，长度字典序       | 先比较长度，短的在前；同长时再用字典序                   | 按长度枚举字符串、先搜索短候选 |
| Filing order，定长字典序 | 限制在某一个 `Σᵏ` 内使用字典序                    | 固定长度编号或编码排序     |

**解释：** Lex 优先看字符，lenlex 优先看长度，filing 只处理同长字符串。按课件定义，filing 分别在每个 `Σᵏ` 上给出全序，未单独规定不同长度之间怎样比较。

**具体例子：** 二进制符号按 `0<1`：lex 中 `001<01<1`；lenlex 中 `1<01<001`。真前缀规则给出 `10<1000`。

**练习 11.2.5 的完整排序：** 原集合为 `{101,010,11,000,10,0010,1000}`。

```text
Lex：    000, 0010, 010, 10, 1000, 101, 11
Lenlex： 10, 11, 000, 010, 101, 0010, 1000
```

**练习 11.2.8：** 对本课程非空字母表，在整个 `Σ*` 上，lex 与 lenlex 相同当且仅当 `|Σ|=1`。

**原因：** 若只有 a，全部字符串是 `λ,a,aa,aaa,...`，两种规则都按长度排列。若有 `a<b`，lex 中 `aa<b`，但 lenlex 中 `b<aa`，因此不同。某个有限词集上，两者也可能碰巧相同，不代表整个 `Σ*` 上相同。

**易混淆与补充：** `Σ*` 包含 λ，lenlex 最前面应包含长度 0 层。有限有序字母表上的 lenlex 是良序；而含两个符号的 lex 不一定是良序，例如 `1>01>001>0001>...` 是无限下降链。全序与良序不能混为一谈。

### 29. 构造指定极值的 Hasse 图：练习 11.6.12（第 58–59 页）

**题目与定义要求：** 构造恰好 5 个元素的偏序，其中有 2 个极大元，且有一个最小元。

**解释与用途：** 从“极大”“最小”的定义反向设计覆盖关系，而不是只看图形像不像树。

**一个具体答案：**

```text
    c       d
    |       |
    a       b
     \     /
        0
```

覆盖关系是 `0≺a≺c`、`0≺b≺d`。完整关系还包括传递得到的 `0≺c`、`0≺d`，以及每个元素的自反关系。

**核对：** 共 5 个元素；c、d 上面没有元素，因此恰好两个极大元；0 小于等于所有元素，因此是最小元。c 与 d 不可比，所以没有最大元。

PPT 第 59 页画出了不同形状的两个答案，说明这种构造不唯一。

### 30. 综合判断题：练习 11.6.6（第 60–61 页）

**用途与方法：** 综合检验全序、有限性、Hasse 图、拓扑排序和极值之间的区别。真命题说明原因；假命题给一个具体反例。

| 命题                            | 结论    | 理由或反例                              |
| ----------------------------- | ----- | ---------------------------------- |
| (a) Σ 全序，则 `Σ*` 的 lex 也是全序    | 真     | 第一处不同字符或真前缀关系决定任意两串的顺序             |
| (b) Σ 全序，则 `Σ*` 的 lenlex 也是全序 | 真     | 长度先比较；同长时由 lex 比较                  |
| (c) 每个有限偏序都有 Hasse 图          | 真     | 可以画出全部覆盖关系                         |
| (d) 每个有限偏序都有拓扑排序              | 真     | 反复选取并删除极小元                         |
| (e) 每个有限偏序都有最小元               | 假     | `{a,b}` 上只有恒等关系，a、b 都极小但互不可比，没有最小元 |
| (f) 每个有限全序都有最大元               | 真，须非空 | 有限队列的最后一个元素；空集没有最大元                |
| (g) 无限偏序不可能有最大元               | 假     | 负整数集 `Z<0` 按通常次序的最大元是 −1           |

### 31. 重要公式与易混淆点汇总

| 要区分的概念         | 应记住的结论                           |
| -------------- | -------------------------------- |
| 等价关系 / 偏序 / 全序 | `R+S+T` / `R+AS+T` / `R+AS+T+L`  |
| 元素 / 等价类 / 商集  | `s∈S`；`[s]⊆S`；`[s]∈S/R`          |
| 代表元不同 / 等价类不同  | `s≠t` 仍可能 `[s]=[t]`              |
| 原像 / 逆函数       | 原像是集合，不要求函数可逆                    |
| 模负元 / 模逆元      | `a+(−a)=0` / `aa⁻¹=1`            |
| 模除法            | 只有 `gcd(a,n)=1` 才能乘以 `a⁻¹` 来除以 a |
| 良定义            | 同一类任选代表元，结果都必须相同                 |
| 对称 / 反对称       | 不是互相否定的两种性质                      |
| 偏序 / 全序        | 偏序允许不可比；全序任意两元素可比                |
| 极小 / 最小        | 没有更小者 / 小于等于所有元素                 |
| 极大 / 最大        | 没有更大者 / 大于等于所有元素                 |
| 上界 / 上确界       | 任意共同上界 / 上界集合的最小元                |
| 极小上界 / 最小上界    | 前者可以多个且互不可比；后者若存在唯一              |
| 最大元 / 上确界      | 最大元须在所考察子集中；上确界可在子集之外            |
| 格 / 任意子集都有上下确界 | 格只要求每一对，不自动涵盖无限子集或空集             |
| 全序 / 良序        | 良序进一步要求每个非空子集都有最小元               |
| 乘积序 / 字典序      | 所有坐标同时比较 / 第一处不同坐标决定             |
| 极大链 / 最长链      | 无法再扩展 / 元素数最多，一般不等同              |
| Hasse 边 / 全部关系 | 边只记录覆盖；自反和传递关系仍属于原偏序             |
